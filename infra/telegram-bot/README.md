# Зв'язок Telegram-бота з адмінкою сайту

`site-sync.patch` — зміна для репозиторію бота (`order_bot`). У Telegram нічого не змінюється. Бот додатково:

- передає на сайт свої заявки (анкету, нік, телефон, статус, менеджера, посилання на тему) і все листування
  (клієнт, менеджери, нотатки команди);
- забирає з сайту відповіді менеджерів і зміни статусу. Відповідь іде клієнту від імені бота, а в тему групи
  потрапляє її копія з позначкою 🌐.

В адмінці заявки бота лежать в окремій вкладці «З Telegram-бота». Сайт їх ніколи не видаляє і не знеособлює:
видалення даних (GDPR) і автоочищення через 24 місяці стосуються лише заявок сайту. Дашборд теж рахує лише
заявки сайту.

Зв'язок завжди починає бот: сайт до сервера бота не звертається і його оновлень не читає, тож друга копія бота
з тим самим токеном ніколи не запускається.

## Як увімкнути

1. На сайті в `.env` вписати `BOT_SYNC_TOKEN` — випадковий рядок щонайменше з 32 символів (`openssl rand -hex 32`),
   і перезапустити `api`.
2. У репозиторії бота:

   ```bash
   git am /шлях/до/site-sync.patch
   python -m pytest            # 1592 тести, справжній токен не потрібен
   ```

3. Розгорнути бота як зазвичай (`docs/DEPLOY.md`, розділ «Встановлення на новий сервер або оновлення»).
4. У `.env` бота на сервері дописати й виконати `systemctl restart order-bot`:

   ```
   SITE_API_URL=https://домен-сайту
   SITE_API_TOKEN=той самий рядок, що BOT_SYNC_TOKEN
   ```

Поки ці два рядки порожні, бот працює точно як до зміни. Під час першого запуску на сайт переходить уся наявна
історія. Щоб спершу перевірити все наживо, варто створити окремого тестового бота в @BotFather і запустити цей
код з його токеном та копією бази, а не з робочим ботом.

## Що змінено в боті

- `bot/site_sync.py` — новий фоновий процес: раз на 5 секунд надсилає на сайт нові заявки й повідомлення та
  забирає відповіді. Позиції зберігаються в таблиці `settings`, тому після перезапуску чи збою сайту нічого не
  губиться й не дублюється.
- `bot/outbox.py` — нове завдання в черзі `site_reply` (доставка відповіді з сайту з тими самими повторами,
  що й решта черги).
- `bot/db.py` — нова колонка `messages.site_message_id`; додається автоматично, як і попередні колонки.
- `bot/config.py`, `bot/__main__.py` — налаштування `SITE_API_URL` / `SITE_API_TOKEN` і запуск процесу.
